    Unidad 5 · Desarrollo de aplicaciones con Symfony¶

    Presentación¶

    En la unidad anterior realizaste una primera aproximación a los frameworks PHP y aprendiste a gestionar dependencias mediante Composer. Estos conocimientos constituyen la base necesaria para comenzar a trabajar con Symfony, uno de los frameworks más utilizados para el desarrollo de aplicaciones web profesionales.

    A lo largo de esta unidad aprenderás a crear y configurar proyectos Symfony, comprenderás la estructura básica de una aplicación y utilizarás las herramientas que proporciona el framework para agilizar el desarrollo. Trabajarás con Symfony CLI y Composer para gestionar proyectos y dependencias, además de conocer la organización de directorios y los principales archivos de configuración.

    También desarrollarás tus primeros controladores y aprenderás a definir rutas para atender las peticiones de los usuarios. Posteriormente utilizarás Twig, el motor de plantillas de Symfony, para generar vistas dinámicas y reutilizables.

    Por último, crearás formularios básicos que te permitirán capturar y procesar información introducida por los usuarios, integrando los diferentes elementos estudiados a lo largo de la unidad.

    Los conocimientos adquiridos en esta unidad servirán de base para las próximas unidades, en las que incorporarás acceso a bases de datos, persistencia de información y desarrollo completo de aplicaciones web con Symfony.

    Objetivos de la unidad¶

    Al finalizar esta unidad serás capaz de:

    • Familiarizarte con el entorno de desarrollo Symfony y comprender la estructura básica de un proyecto.
    • Conocer el proceso de creación y puesta en marcha de una aplicación Symfony.
    • Utilizar Symfony CLI y Composer para gestionar proyectos y dependencias.
    • Configurar adecuadamente un entorno de desarrollo Symfony.
    • Comprender el uso de las variables de entorno y los principales archivos de configuración.
    • Crear controladores para gestionar peticiones y generar respuestas dinámicas.
    • Definir rutas y utilizar parámetros en las URL.
    • Trabajar con el motor de plantillas Twig para construir vistas dinámicas.
    • Navegar entre páginas utilizando el sistema de rutas de Symfony.
    • Crear y procesar formularios básicos para la entrada de datos.

    Temporalización¶

    La dedicación estimada para esta unidad es de 24 horas distribuidas entre el estudio de los contenidos, el desarrollo de ejemplos prácticos, la realización de las actividades de aprendizaje y la elaboración de la actividad evaluable.

    Recomendaciones de estudio¶

    Para aprovechar mejor la unidad se recomienda:

    • Instalar y configurar todas las herramientas antes de comenzar los ejercicios.
    • Seguir los contenidos en el orden propuesto, ya que los conceptos se construyen de forma progresiva.
    • Crear y ejecutar cada ejemplo práctico mientras se estudian los contenidos.
    • Analizar la estructura de directorios generada por Symfony.
    • Practicar la creación de rutas y controladores modificando los ejemplos propuestos.
    • Experimentar con Twig para comprender el flujo de información entre controladores y vistas.
    • Probar distintos tipos de formularios y observar cómo Symfony procesa los datos enviados.
    • Consultar regularmente la documentación oficial de Symfony para familiarizarse con su ecosistema y sus buenas prácticas.

    Consejo

    Symfony es un framework muy amplio. Durante esta unidad céntrate en comprender la estructura general de una aplicación, el funcionamiento de las rutas, los controladores y las vistas. Dominar estos conceptos facilitará enormemente el aprendizaje de contenidos más avanzados en las siguientes unidades.
