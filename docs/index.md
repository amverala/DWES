Bienvenido al sitio web del módulo.

En este espacio encontrarás los materiales, actividades, ejemplos, ejercicios y recursos utilizados durante el curso de Desarrollo Web en Entorno Servidor.

## Cómo utilizar este sitio

- Accede a la unidad indicada por el profesorado.
- Sigue los contenidos en el orden recomendado.
- Realiza las actividades propuestas.
- Prueba y modifica los ejemplos de código.
- Utiliza el menú lateral para navegar entre secciones.

!!! info "Recomendación"

    Se aconseja seguir las unidades de forma secuencial, ya que los conceptos trabajados en cada una sirven de base para las siguientes.
