# Unidad 3 · Programación orientada a objetos en PHP

## Presentación

En la unidad anterior aprendiste los elementos fundamentales del lenguaje PHP y desarrollaste programas utilizando variables, estructuras de control y funciones. A partir de esos conocimientos, en esta unidad darás un paso más para organizar aplicaciones de forma modular, reutilizable y mantenible mediante la programación orientada a objetos.

Los conceptos fundamentales de la orientación a objetos ya han sido estudiados previamente en el módulo de Programación utilizando Java. Por ello, el objetivo de esta unidad no es volver a introducir dichos conceptos, sino aprender cómo se implementan en PHP y conocer las particularidades que presenta este lenguaje.

A lo largo de la unidad trabajarás con clases, objetos, encapsulación, herencia, polimorfismo, clases abstractas, interfaces y espacios de nombres. Además, aplicarás estos conceptos mediante actividades prácticas orientadas al desarrollo de aplicaciones web.

Los conocimientos adquiridos servirán de base para las siguientes unidades del módulo, en las que se abordarán aplicaciones más complejas y arquitecturas de desarrollo profesionales.

### Objetivos de la unidad

Al finalizar esta unidad serás capaz de:

- Comprender las características de la programación orientada a objetos en PHP.
- Definir clases y crear objetos utilizando la sintaxis propia del lenguaje.
- Implementar atributos y métodos con distintos niveles de visibilidad.
- Utilizar constructores y destructores para inicializar objetos.
- Aplicar técnicas de encapsulación mediante métodos de acceso.
- Reutilizar código mediante herencia.
- Aplicar polimorfismo a través de la redefinición de métodos.
- Diseñar jerarquías de clases utilizando clases abstractas e interfaces.
- Utilizar miembros estáticos y constantes de clase.
- Organizar aplicaciones mediante espacios de nombres.
- Desarrollar programas aplicando buenas prácticas de programación orientada a objetos.

### Recomendaciones de estudio

Para aprovechar mejor la unidad se recomienda:

- Leer los contenidos en el orden propuesto.
- Escribir y ejecutar todos los ejemplos de código.
- Comparar las soluciones desarrolladas en PHP con los conocimientos adquiridos previamente en Java.
- Realizar las actividades de aprendizaje antes de comenzar la tarea evaluable.
- Diseñar y probar tus propias clases para afianzar los conceptos estudiados.
- Resolver las dudas que surjan durante el estudio a través de los canales habilitados por el profesorado.

!!! tip "Consejo"
    La programación orientada a objetos se aprende practicando. Experimenta modificando los ejemplos y creando nuevas clases para comprender mejor el comportamiento de los objetos y las relaciones entre ellos.
