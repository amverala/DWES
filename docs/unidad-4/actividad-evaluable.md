!!! warning "Actividad evaluable"

    En esta actividad aplicarás los conocimientos adquiridos sobre Composer y gestión de dependencias mediante el desarrollo de una pequeña aplicación PHP y la grabación de un vídeo explicativo.

## Enunciado

Desarrolla una aplicación PHP que utilice Composer para instalar y utilizar una dependencia externa.

Puedes utilizar alguna de las siguientes librerías:

- Monolog
- Faker
- Dompdf
- PHPMailer

También puedes proponer otra librería si consideras que resulta adecuada para el proyecto.

---

## Entrega

La entrega consistirá exclusivamente en un **vídeo explicativo**.

!!! note "Duración máxima"

    El vídeo deberá tener una duración máxima de **8 minutos**.

    Se recomienda preparar previamente la explicación para aprovechar mejor el tiempo disponible.

---

## Contenido mínimo del vídeo

Durante la grabación deberás mostrar y explicar:

1. La estructura de tu proyecto.
2. El archivo `composer.json`.
3. La instalación de la dependencia mediante Composer.
4. El código desarrollado.
5. El uso de `vendor/autoload.php`.
6. La ejecución de la aplicación.
7. El funcionamiento correcto de la librería utilizada.

---

## Recomendaciones

!!! tip "Consejo"

    Explica cada paso con tus propias palabras.

    El objetivo no es únicamente mostrar que la aplicación funciona, sino demostrar que comprendes:

    - Qué es una dependencia.
    - Para qué sirve Composer.
    - Cómo se instala una librería.
    - Cómo funciona el autoload.
    - Cómo se utiliza la dependencia dentro del proyecto.

---

## Objetivo de la actividad

!!! success "Aplicación práctica"

    Esta actividad te permitirá aplicar los conocimientos adquiridos sobre gestión de dependencias, Composer y autoload en un proyecto real.
