# Actividades evaluables

## Actividad 4. Instalación del servidor local

### Tareas

1. Instala una distribución WAMP o XAMPP en tu ordenador.
2. Comprueba que los servicios principales funcionan correctamente.
3. Realiza una captura de pantalla del panel de control.
4. Entrega la evidencia utilizando el medio indicado por el profesor.

### Evidencia

✅ Captura de pantalla del entorno funcionando correctamente.

---

## Actividad 5. Instalación de Visual Studio Code

### Tareas

1. Descarga Visual Studio Code para tu sistema operativo.
2. Instálalo siguiendo las instrucciones oficiales.
3. Instala las siguientes extensiones:

    - Spanish Language Pack for Visual Studio Code
    - PHP IntelliSense
    - Bracket Pair Color DLW
    - PHP Namespace Resolver
    - PHP Class Creator
    - PHP Snippet Pack
    - PHP Getters & Setters

4. Realiza una captura de pantalla donde se observe el IDE y las extensiones instaladas.

### Evidencia

✅ Captura de pantalla del IDE correctamente configurado.
