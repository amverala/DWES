    Actividades

    Introducción

    A lo largo de esta unidad has conocido los conceptos fundamentales necesarios para comenzar a desarrollar aplicaciones web en entorno servidor.

    Has estudiado:

    • Los principales sistemas operativos.
    • La arquitectura cliente-servidor.
    • El funcionamiento de un servidor local.
    • El entorno de desarrollo Visual Studio Code.

    Ahora es el momento de poner en práctica lo aprendido.

    Actividades de reflexión

    Actividad 1. Sistemas operativos y servidores web

    Investiga qué sistema operativo utilizan habitualmente los servidores web de Internet.

    1. ¿Qué sistema operativo es el más utilizado?
    2. ¿Cuáles son sus principales ventajas?
    3. ¿Por qué crees que domina el mercado de los servidores?

    Actividad 2. Cliente y servidor

    Explica con tus propias palabras qué ocurre cuando escribes una dirección web en el navegador y pulsas la tecla Enter.

    Actividad 3. Aplicaciones web de uso cotidiano

    Selecciona tres aplicaciones web que utilices habitualmente e identifica cliente y servidor.

    Actividades evaluables

    Actividad 4. Instalación del servidor local

    Tareas

    1. Instala una distribución WAMP o XAMPP en tu ordenador.
    2. Comprueba que los servicios principales funcionan correctamente.
    3. Realiza una captura de pantalla del panel de control.
    4. Entrega la evidencia utilizando el medio indicado por el profesor.

    Evidencia

    ✅ Captura de pantalla del entorno funcionando correctamente.

    Actividad 5. Instalación de Visual Studio Code

    Tareas

    1. Descarga Visual Studio Code para tu sistema operativo.
    2. Instálalo siguiendo las instrucciones oficiales.

    3. Instala las siguientes extensiones:

      • Spanish Language Pack for Visual Studio Code
      • PHP IntelliSense
      • Bracket Pair Color DLW
      • PHP Namespace Resolver
      • PHP Class Creator
      • PHP Snippet Pack
      • PHP Getters & Setters

    4. Realiza una captura de pantalla donde se observe el IDE y las extensiones instaladas.

    Evidencia

    ✅ Captura de pantalla del IDE correctamente configurado.
