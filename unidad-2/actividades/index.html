    Actividades¶

    Introducción¶

    En esta unidad has adquirido los conocimientos fundamentales del lenguaje PHP: variables, tipos de datos, estructuras de control y funciones.

    Las siguientes actividades son entregables y evaluables. Cada una de ellas plantea una situación profesional sencilla que deberás resolver mediante un programa PHP ejecutable desde el navegador.

    Las actividades presentan una dificultad progresiva. Se recomienda realizarlas en el orden propuesto.

    Todos los programas deberán ejecutarse correctamente desde el navegador y guardarse con la extensión .php.

    Actividad entregable 1 · Cálculo de la nómina semanal¶

    Contexto¶

    Una pequeña empresa desea automatizar el cálculo del salario semanal de sus trabajadores.

    Enunciado¶

    Desarrolla una aplicación denominada:

    nomina.php

    La aplicación deberá calcular el salario semanal de un empleado a partir de la información que consideres necesaria.

    Además de obtener el salario, el programa deberá mostrar claramente todos los datos utilizados para realizar el cálculo.

    Requisitos¶

    • Utilizar variables para almacenar la información.
    • Realizar operaciones aritméticas para obtener el resultado.
    • Mostrar los datos y el salario calculado mediante PHP.
    • Organizar la salida de forma clara y legible.
    • Ejecutarse correctamente desde el navegador.

    Entrega¶

    Sube el archivo:

    nomina.php

    Actividad entregable 2 · Evaluación de un estudiante mediante funciones¶

    Contexto¶

    Un centro educativo necesita calcular automáticamente la calificación final obtenida por un estudiante a partir de las notas de varias actividades evaluables.

    Enunciado¶

    Desarrolla una aplicación denominada:

    calculadora-notas.php

    La aplicación deberá utilizar funciones para calcular la nota media de un estudiante y determinar si ha superado la evaluación.

    La solución deberá mostrar:

    • Las calificaciones utilizadas.
    • La nota media obtenida.
    • El resultado final de la evaluación.

    Requisitos¶

    • Definir al menos una función creada por el usuario.
    • Utilizar parámetros en las funciones.
    • Utilizar valores de retorno mediante return.
    • Aplicar declaraciones de tipo de PHP 8.
    • Utilizar alguna estructura condicional para determinar el resultado final.
    • Ejecutarse correctamente desde el navegador.

    Entrega¶

    Sube el archivo:

    calculadora-notas.php

    Actividad entregable 3 · Informe académico de un grupo¶

    Contexto¶

    La coordinación de un ciclo formativo necesita generar un informe resumido del rendimiento académico de un grupo de estudiantes.

    Enunciado¶

    Desarrolla una aplicación denominada:

    informe-academico.php

    La aplicación deberá procesar una colección de calificaciones correspondiente a varios estudiantes y generar un informe estadístico básico.

    El informe deberá incluir, como mínimo:

    • Las calificaciones almacenadas.
    • La situación académica de cada estudiante (aprobado o suspenso).
    • El número total de aprobados.
    • El número total de suspensos.
    • La nota media del grupo.

    Requisitos¶

    • Utilizar al menos un array.
    • Recorrer la colección de datos mediante foreach.
    • Utilizar funciones definidas por el usuario.
    • Utilizar estructuras condicionales para clasificar las calificaciones.
    • Aplicar declaraciones de tipo de PHP 8.
    • Ejecutarse correctamente desde el navegador.

    Entrega¶

    Sube el archivo:

    informe-academico.php

    Criterios generales de evaluación¶

    En todas las actividades se valorará:

    • Corrección del funcionamiento del programa.
    • Uso adecuado de los contenidos estudiados en la unidad.
    • Legibilidad y organización del código.
    • Correcta indentación.
    • Nombres significativos para variables y funciones.
    • Aplicación de declaraciones de tipo cuando sea posible.
    • Ausencia de errores de ejecución.

    Lista de comprobación¶

    Antes de realizar la entrega verifica que:

    • [ ] El programa se ejecuta correctamente en el navegador.
    • [ ] El archivo tiene extensión .php.
    • [ ] No aparecen errores de sintaxis.
    • [ ] El código está correctamente indentado.
    • [ ] Se utilizan nombres descriptivos.
    • [ ] Se han aplicado los contenidos estudiados en la unidad.

    Resumen¶

    Las actividades propuestas permiten aplicar progresivamente los contenidos trabajados durante la unidad:

    Actividad Contenidos principales
    Actividad 1 Variables y operadores
    Actividad 2 Funciones, parámetros y retorno
    Actividad 3 Arrays, foreach, funciones y estructuras de control

    La superación de estas actividades demuestra que has adquirido las competencias básicas necesarias para continuar con el estudio del desarrollo web en entorno servidor utilizando PHP.
